# 保安·李长林（60.505 秒）

感人历史故事风 HTML 动画。1920×1080，时长 60.505 秒，**无字幕、无音频**（配音与字幕后期合成）。
画面由 HTML + SVG + Canvas 及随包提供的透明 PNG、历史资料照组成，不依赖网络。下载整个作品文件夹后双击 `index.html` 即可播放。

## 第一轮进度

本工程始终使用 `index.html` 一个主入口，保留完整 **60.505 秒**时间轴。已完成“挑担受辱与参加红军”和“斯诺采访与笔记”的首轮调整。其他部分在同一工程中按下列队列逐段推进。正式目录不包含历次实验、A/B 对照、视频预览或重复版本树。

### 挑担受辱与参加红军（24.7–35.2秒）

- `js/scenes3.js`：接入人物和道具，保持本段与前后镜头的衔接
- `js/挑担参军-人物动作.js`：农民、红军分层姿态，肩托和握持约束，换装及粮筐退出
- `js/挑担参军-农民图层.js`、`js/挑担参军-红军图层.js`：图层位置、裁切范围、锚点与中文素材路径
- `js/挑担参军-鞭子动作.js`、`js/挑担参军-肩背回弹.js`：两次抽击、尾梢跟随、局部衣料压缩及肩背躯干头部的错峰恢复
- `js/挑担参军-肩上步枪.js`：肩上横扛步枪的形状、握点与木纹
- `js/挑担参军-过渡轮廓.js`、`js/挑担参军-局部材质.js`：与原场景衔接所需的轮廓、手势和局部材质辅助
- `images/挑担受辱与参加红军/`：农民 16 张、红军 21 张、施鞭手 1 张，共 38 张运行 PNG；不与其他段的照片和史料素材混放

农民和红军使用本项目已定稿的农民动作结构图拆件及同源布料军装改造。结构图按选定方向生成，不是历史照片或真实肖像。身体、衣服与手脚分别变换；原画未提供的军帽、袖口和衣摆由同源布料裁片补成。军装是风格化解释，不宣称精确复刻历史制服。

扁担和步枪随肩部作克制的微动，粮筐轻摆，手跟随握点；双脚保持原位，没有假装已经制作完整走路循环。两次主要抽击落在约 **25.50 秒和 27.30 秒**。每次先蓄势，再加速向下，接触后尾梢甩开，隐藏并停顿，再从同一初态重播。身体响应由局部压缩到肩、躯干、头部依次跟随；农民到红军的换装仍在约 28.85–29.77 秒完成。

动作采用可控关键曲线、接触编排与次级弹簧响应，是面向画面的动画方法，不是完整绳索或人体软体物理仿真。最终配音尚未提供，当前内部动作落点不能替代实际配音校对。

## 打开与播放

- 推荐用 Chrome 或 Edge 打开 `index.html`（开启硬件加速）。
- 快捷键：空格 播放/暂停 · ←/→ 前后 1 秒（按住 Shift 逐帧）· Home 回到开头 · F 全屏 · G 显示/隐藏素材位参考框 · H 隐藏控制条。
- 网址参数：`?autoplay` 打开即播放，`?t=35.2` 从指定秒数开始，`?clean` 隐藏控制条（录屏用），`?guides` 显示素材位参考框。
- 画面按窗口等比缩放。直接录屏时，请在 1920×1080 屏幕上全屏播放，并从第一帧开始录。

## 导出视频（推荐）

`render.js` 逐帧截图并编码，帧精确，与电脑快慢无关：

```bash
npm i playwright && npx playwright install chromium   # 首次使用
node render.js                     # 1920×1080、30fps → 保安-李长林.mp4（需要 ffmpeg）
node render.js --fps 25            # 25fps
node render.js --scale 2           # 3840×2160
node render.js --frames out        # 只导出 PNG 序列（不需要 ffmpeg）
node render.js --workers 4         # 并行渲染路数（默认按 CPU 核数自动选择）
```

按 30fps 导出共 1816 帧（最后一帧为 60.500 秒），剪辑时按配音长度对齐即可。

## 软件预览备用工具

`工具/` 仅保存复现预览所需的四个脚本和依赖声明，不包含实验报告或历史版本。优先使用上面的真实浏览器导出；此备用工具以软件 DOM、SVG 和 Canvas 合成画面，不能用于证明真实浏览器的像素一致性。

依赖 Node.js 24+。在作品目录执行：

```bash
npm install --prefix 工具
node 工具/软件渲染.cjs . 预览帧 25.5,27.3,29.4,32 1280
node 工具/连续帧.cjs source=. out=预览帧 start=24.7 end=35.2 fps=60 width=1280
ffmpeg -framerate 60 -i 预览帧/f%05d.png -c:v libx264 -pix_fmt yuv420p -movflags +faststart 挑担受辱与参加红军-正常速度预览.mp4
```

`npm install` 仅在首次准备依赖时需要网络。已有依赖可用环境变量 `ANIMATION_RENDER_NODE_MODULES` 指向相应 `node_modules` 目录；项目不写死任何机器路径。播放页面本身不需要这些工具或 Node.js。输出目录应使用单独的临时位置，预览帧不提交到仓库。 连续帧工具默认每12帧启用一个短进程，完成后释放原生SVG/Canvas内存；可用 `batchFrames=6` 降低单批峰值，或以 `resume=1` 跳过已完整输出的PNG并续渲。帧先写到临时文件，完整写入后再改为正式帧名；不要把临时文件交给编码器。

## 叙事主线：物件的变换

整片没有硬切，每次转场都由上一个物件“变成”下一个物件，或由同一束光、同一个位置接过去：

灯火 → 旧照片 → 照片里的破碗与借据 → 碗的裂缝长成龟裂的土地 → 一行草鞋脚印 → 汇入大队脚印 → 红布掠过 → 八角帽红星 → 斯诺相机镜头里的红星倒影 → 笔记本与钢笔 → 墨滴 → 扁担 → 步枪 → 火把长队 → 结霜的红星 → 燃烧的借据 → 万家灯火 → 一簇火苗 → 出路 → 山丹丹花 → 铁水 → 铜元 → 窑洞窗台。

首尾呼应：开头的窑洞拱窗、窗花与破碗，在结尾变成朝阳里的窗花和洗净还回的碗；当年给地主挑重担的扁担，最后靠在给乡亲挑满的水缸旁；压在碗下、按着红手印的借据，被红星的光点燃。
