# 保安·李长林：完整动画

HTML 时间轴 60.505 秒；MP4 固定 24fps、1452 帧、60.500 秒，静音，1280×720。视频比源时间轴短 0.005 秒。画面无后期字幕，配音与字幕由后期合成。工程只有一个主入口 `index.html`，图片全部保存在本地。

## 内容与时间

- 0–38 秒：保留正式版本的窑洞、农家、足迹、采访、挑担与红军行军画面
- 38.55–43 秒：原地契按既有遮罩燃尽，焦边和余烬保留
- 40.7–51.6 秒：真实高程地形上的多阶段四渡示意，红路线反复转折，多路蓝军从不同方向施压，交战烟火跟随实际地理投影
- 51.6–54 秒：相机围绕红军前锋横向转动，保持约49度俯角，红头连接纸山红线与暖谷
- 52.1–54 秒：连续纸山背景随同一相机侧转；先接入远景与暖谷，再接入近景材质，红头不中断
- 54–60.505 秒：七个行军人物各自换用四步态，错时烟火由四幅独立阶段变化，百姓三组轻微独立活动，山体有补底视差

画面不添加地名、年份或后期字幕。

## 打开与控制

用 Chrome 或 Edge 打开 `index.html`。空格播放/暂停，左右键前后 1 秒，Shift 加左右键逐帧（24fps），Home 回到开头，F 全屏，H 隐藏控制条。

可加参数：`?autoplay`、`?t=49`、`?clean`。舞台内部仍沿用正式源的 1920×1080 坐标，最终输出等比缩为 1280×720。

浏览器接口：

```js
await window.__anim.ready;
await window.__anim.seek(49);
// 导出时必须等待当前地形图片解码：
await window.__anim.renderAtAsync(49);
```

## 逐帧渲染

Node.js 24+，依赖见 `工具/package.json`。软件合成忠实执行本地场景代码、SVG、Canvas 与图片，但不能作为原生浏览器像素一致性的证明。

```bash
npm install --prefix 工具
node 工具/连续帧.cjs source=. out=输出帧 start=0 end=60.505 fps=24 width=1280 batchFrames=12 resume=1
```

可用 `part=0 parts=2` 与 `part=1 parts=2` 分两路。帧文件先完整写入再改名，可中断续渲。帧号从 `f00000.png` 到 `f01451.png`：第 i 帧采样时刻为 i/24，共 1452 帧，最后一帧采样 60.458333 秒。所有帧固定显示 1/24 秒，MP4 时长为 60.500 秒，比 HTML 时间轴短 0.005 秒；不使用可变末帧时长。

浏览器导出入口为 `node render.js`，需要 Playwright 与 ffmpeg；默认 1280×720、固定 24fps。`node render.js --frames 输出帧` 仅保存 PNG。

## 文件与来源

- `js/scenes1.js`、`scenes2.js`、`scenes3.js` 及原人物动作模块：正式源前段，未作内容改动
- `js/scenes4.js`：原地契燃烧与余烬
- `js/最终地形与纸山.js`：异步资源调度、地理战点烟火、连续转场合成
- `js/路线相机.js`：逐帧真实相机、前锋屏幕锚点、切线与战点遮挡信息
- `js/layered-finale.js`：真正独立透明群众、行军步态、四阶段烟火与补底纸山
- `js/镜头分层投影.js`：围绕前锋锚点的纸景透视侧转
- `js/最终分层素材.js`：补底纸图与三类透明图片，内置data URI，离线像素读回无需关闭安全限制
- `images/terrain/`：同一个实测高程三维地形逐帧渲染的WebP
- `images/` 其他文件：正式版人像、地契、人物切片、采访照片与字体来源记录

历史与素材来源见 [史料与素材说明](史料与素材说明.md) 和 [地形来源](地形来源.md)。本工程不含原始DEM或重建过程视频。
