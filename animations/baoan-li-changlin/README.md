# 保安·李长林（60.505秒）

1920×1080 HTML动画，无音轨和后期字幕；配音与字幕由后期合成。画面使用HTML、SVG、Canvas及工程内图片，播放不依赖网络。完整作品仅有一个主入口`index.html`。

本版按用户更新的main提交`c5bc17907b0754a4e53b79c18cdb3a13483ec864`对齐人像、地契、黎明粮袋结尾和画面稳定性，同时保留已批准的人物动作、草鞋足迹与材质处理。

## 当前内容

- **保安窑洞与贫苦农家（0–10.4秒）**：油灯照亮灰度人物设定插画；6–6.85秒通过纸面淡入农家回忆。竖幅地契在碗旁整张呈现，粗瓷碗的裂纹接入旱地。
- **磨难足迹与红星（10–15.1秒、34.9–39.1秒）**：前掌与后跟有区别的草鞋压痕，清晰与断续编纹交错；原脚印队列、落点与出现顺序保留。红布、布帽与霜层沿用已定材质。
- **斯诺采访与笔记（14.6–24.7秒）**：钢笔分段书写采访提纲，旁置同年代黄土风景照片。照片卡面没有姓名、年份或资料说明，来源在工程文档中。书写完成、抬笔、落墨及进入农民镜头的节奏保持。
- **挑担受辱与参加红军（24.7–35.2秒）**：无面孔人物沿用原始切片。两次鞭击在约25.50、27.30秒重复，接触后肩背、胸部与头部错峰响应，回弹后隐藏暂停。右侧指责手以设定图的灰纸、关节线和袖口折面语言细化，保持指向与时刻。换装约28.85–29.77秒完成；29.8–30.0秒渐入克制的交替轻步，支撑足跟随雪坡，手、肩、枪共用锚点。
- **地契燃尽与万家灯火（38.6–53.6秒）**：用户提供的地契按原图比例完整显示，窄热边与焦层随既有遮罩推进；火星、红星闪光接力和村落点灯节奏保持。
- **黎明粮袋与群众纪律（53–60.505秒）**：山梁天亮，54.8秒开始淡入窗台上的碗与粮袋，随后拉开到窑洞、水缸、扁担、草束和扫帚。

全片环境微抖已关闭，情节中的`POST.shake`保留。两处交叉淡入由旧背景托到新景完全显现：地契灯火背景至53.7秒，黎明背景至55.65秒；不挪动新景入场、相机或配音落点。

## 图片与来源

- `images/li-gray.jpg`是当前相框用灰度人物插画，`images/li-source.png`保存main提供的原始设定图。相框采用完整容纳显示；此图用于角色设计，不宣称为真实李长林历史肖像。
- `images/deed.png`是用户在main提供的竖幅地契素材。碗旁显示尺寸约200×250，燃烧虚拟表面经水平比例恢复约560×700，保留全图与文字，不添加新的姓名、日期或金额，也不对文物真实性作额外认定。
- 采访风景为T.A.Bisson相关1937年赴延安途中黄土地区照片，书中题为“Loess Country”。它用作同年代环境参考，不标作1936年保安现场，也不归为Edgar Snow摄影。完整出处、馆方权利说明与运行图片处理记录见`images/斯诺采访/`内的来源文件。
- 人物运行切片位于`images/挑担受辱与参加红军/`，共38张农民、军装和施鞭手PNG。指责手是参照已有手部材质语言派生的指向姿态，不声称从设定图直接裁得该姿态。
- 采访提纲是根据本片台本整理的动画文本，不是斯诺原手稿复刻。英文 Caveat 与中文 Long Cang 手写字形按 SIL Open Font License 1.1 使用；文字以 SVG 路径离线显示。重构说明仅在工程文档中，不出现在纸页上。许可、23KB 中文字形子集及可维护字稿保留在工程内。
- 修改采访中文：编辑 `images/斯诺采访/采访中文字稿.json`，运行 `python 工具/重建采访中文字迹.py`（需要 fontTools）。新增字若不在子集中，按字体来源取得官方完整 Long Cang，再用 `--font` 参数重建；不可把缺字静默替成方框。
- 村落门窗结构参考陕西省非物质文化遗产数字博物馆《吴起窑洞门窗制作技艺》：https://www.sxfycc.com/home/Index/library_detail.html?id=376 。工程使用自绘结构，没有复制该参考的照片像素。

## 素材和配音配置

`materials.js`中的`MATERIALS`控制人像、采访照片和地契路径。人像适合约4:5；当前采访卡适合横幅风景；当前地契按约4:5配置。更换图片时同步核对比例与来源说明。

同文件中的`TIMING`保存语义落点。最终配音需要调整时，可通过这些时间值对齐；当前交付总时长保持60.505秒。页面默认正常1×播放。

## 打开与播放

- 推荐用 Chrome 或 Edge 打开 `index.html`（开启硬件加速）。
- 快捷键：空格 播放/暂停 · ←/→ 前后 1 秒（按住 Shift 逐帧）· Home 回到开头 · F 全屏 · G 显示/隐藏素材位参考框 · H 隐藏控制条。
- 网址参数：`?autoplay` 打开即播放，`?t=35.2` 从指定秒数开始，`?clean` 隐藏控制条（录屏用），`?guides` 显示素材位参考框。
- 画面按窗口等比缩放。直接录屏时，请在 1920×1080 屏幕上全屏播放，并从第一帧开始录。

## 导出视频（推荐）

`render.js` 逐帧截图并编码，帧精确，与电脑快慢无关：

```bash
npm i playwright && npx playwright install chromium   # 首次使用
node render.js                     # 1920×1080、30fps → 保安-李长林.mp4（需要 ffmpeg）
node render.js --fps 25            # 25fps
node render.js --scale 2           # 3840×2160
node render.js --frames out        # 只导出 PNG 序列（不需要 ffmpeg）
node render.js --workers 4         # 并行渲染路数（默认按 CPU 核数自动选择）
```

按 30fps 导出共 1816 帧（最后一帧为 60.500 秒），剪辑时按配音长度对齐即可。

## 软件预览备用工具

`工具/` 仅保存复现预览所需的四个脚本和依赖声明，不包含实验报告或历史版本。优先使用上面的真实浏览器导出；此备用工具以软件 DOM、SVG 和 Canvas 合成画面，不能用于证明真实浏览器的像素一致性。

依赖 Node.js 24+。在作品目录执行：

```bash
npm install --prefix 工具
node 工具/软件渲染.cjs . 预览帧 25.5,27.3,29.4,32 1280
node 工具/连续帧.cjs source=. out=预览帧 start=24.7 end=35.2 fps=60 width=1280
ffmpeg -framerate 60 -i 预览帧/f%05d.png -c:v libx264 -pix_fmt yuv420p -movflags +faststart 挑担受辱与参加红军-正常速度预览.mp4
```

`npm install` 仅在首次准备依赖时需要网络。已有依赖可用环境变量 `ANIMATION_RENDER_NODE_MODULES` 指向相应 `node_modules` 目录；项目不写死任何机器路径。播放页面本身不需要这些工具或 Node.js。软件适配器默认把重复的无额外样式生成纹理共享为单个定义，减少重复数据；这是离线预览优化，不改动画运行画面。需要核查时可通过软件渲染API的 `shareTextureImages:false` 关闭。

输出目录应使用单独的临时位置，预览帧不提交到仓库。 连续帧工具默认每12帧启用一个短进程，完成后释放原生SVG/Canvas内存；可用 `batchFrames=6` 降低单批峰值，或以 `resume=1` 跳过已完整输出的PNG并续渲。帧先写到临时文件，完整写入后再改为正式帧名；不要把临时文件交给编码器。

## 预览与验证范围

交付包含完整源工程、全片预览与六段离线对照。离线对照的B侧来自同一份当前运行源，A侧保留各段历史画面；足迹与红星预览分为两章，中间省略的19.8秒有明确章节标示。

软件预览执行实际场景JavaScript、SVG、Canvas和PNG，并检查素材解码、时间定位、动作锚点、交叠边界、逐帧时间戳及完整视频解码。它仍不能证明原生浏览器合成和实播像素一致，最终设备性能与配音合成需要在使用环境核对。

## 文件结构

- `index.html`：舞台、播放控制和唯一主入口
- `materials.js`：素材路径与配音时间落点
- `js/core.js`、`js/objects.js`：数学、纹理及共享物件
- `js/scenes1.js`：窑洞油灯、相框人像、农家、破碗与地契
- `js/scenes2.js`：脚印、红布、红星、采访、笔记与墨滴
- `js/scenes3.js`与`js/挑担参军-*.js`：挑担、受击、换装、持枪轻步与结霜红星
- `js/scenes4.js`：地契燃烧、灯火、山路火苗与风雨
- `js/scenes5.js`：黎明与粮袋窗台收束
- `js/斯诺采访-笔记素材.js`：采访文字、钢笔路径与风景照片卡
- `images/`：运行素材及来源记录
- `render.js`、`工具/`：浏览器导出与软件预览工具

正式目录不保存实验视频、A/B历史版本树或依赖安装目录。
